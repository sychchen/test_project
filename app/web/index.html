按日期取数的三种口径：① 增量采集日线 = 相对窗口「最近 N 个交易日」（默认 2 日）；② 采集指定时间段 = 绝对区间「起~止」。 两者写的是同一张表 stock_daily_quote、同一批列、同源同口径（腾讯 fqkline 不复权 + 新浪兜底），因此区间包含最近交易日时会更新同一批行，属正常覆盖、不会冲突； 差异只在取数窗口，且区间模式不会清掉 pe/pb/市值/换手率（这些列由「估值快照入日线」维护）。
③ 估值快照 / 采集资金流向 / 采集当日分时 = 固定作用于最新交易日或当日，与时间段仅在「最新一天」重叠，且分别写日线的估值列、stock_money_flow、stock_minute_quote（后两者是独立的表）。
其余按钮（股票列表+基本面、上市日期、板块标签、东财概念、指数日线）不含日期维度或写别的表，与「指定时间段」无交叉。
