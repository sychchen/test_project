# 04 · 一周主线低吸策略（WEEKLY_MAINLINE）量化实现说明

> 来源：`docs/03-一周策略.md`《主线分歧低吸 + 轮动套利策略》的工程化落地
> 代码：`app/strategy/weekly_mainline.py`（已注册进选股框架，CLI/API/回测通用）
> 日期：2026-09-08

## 一、策略总览

| 项目 | 内容 |
|---|---|
| 策略代码 | `WEEKLY_MAINLINE` |
| 策略名称 | 一周主线低吸 |
| 持仓周期 | T+1 ~ T+3（隔夜至 3 个交易日） |
| 运行频率 | 每个交易日盘后自动运行 |
| 目标收益 | 单笔 2%-8%，胜率目标 55%-65% |
| 股票池 | 大A（沪深主板+创业板，688/689 科创板由框架统一剔除） |

## 二、选股逻辑

### 主线池（AI 算力硬件，优先级最高，取前 3 只）

同时满足：

| # | 条件 | 参数（默认值） |
|---|---|---|
| 1 | 板块命中（双通道，任一即可） | 概念：CPO / PCB / 光通信 / 光模块 / AI服务器 / 算力 / 高速连接 / 液冷 / 铜缆；**或行业（申万）：通信 / 电子 / 计算机** |
| 2 | 流通市值 | 50 亿 ~ 800 亿 |
| 3 | 量比（当日量/20日均量） | 1.5 ~ 8 |
| 4 | 相对强度 | 5日涨幅 > 0 且 20日涨幅 > 5% |
| 5 | RSI(14) | < 70（不追过热） |
| 6 | 当日涨幅 | -2% ~ +7%（只做分歧低吸） |
| 7 | 排除 | ST、停牌（最近交易日无行情）、库内历史 < 21 日（新股代理） |

评分 = `3日量比×0.4 + 当日量比×0.3 + (20日涨幅/10)×0.3`，降序取前 3。

### 轮动池（农业/资源，主线分歧时启用，取前 2 只）

**触发条件**（任一）：主线候选 < 2 只，或主线板块（双通道）当日平均涨幅 > 5%（过热）。

| # | 条件 | 参数（默认值） |
|---|---|---|
| 1 | 板块命中（双通道，任一即可） | 概念：种植 / 农业 / 化肥 / 养殖 / 工业金属 / 铜 / 油气 / 石油 / 煤炭 / 黄金 / 稀土；**或行业（申万）：农林牧渔 / 有色金属 / 石油石化 / 煤炭 / 钢铁** |
| 2 | 流通市值 | 30 亿 ~ 200 亿 |
| 3 | 量比 | ≥ 1.8 |
| 4 | 当日涨幅 | -1% ~ +5% |
| 5 | 20日涨幅 | -10% ~ +15%（防高位接力） |

评分 = `当日量比×0.5 + 3日量比×0.5`，降序取前 2。
触发轮动时产出 = 主线第 1 名 + 轮动前 2 名。

### 大盘环境过滤（前置闸门）

全市场 MA5 > MA20 的股票占比（市场宽度）< 45% 时，当日不开仓、返回空结果。
（上证指数 5/20 日线死叉的代理指标，本系统未采集指数行情）

## 三、原文档指标 → 本系统实现映射

| 原文档指标 | 本系统实现 | 说明 |
|---|---|---|
| 所属板块（CPO/PCB/农业等） | **双通道取并集**：`stock_basic.concepts` 关键字包含 **或** `stock_basic.industry`（申万行业）命中 | 新浪概念标签覆盖差，2026-09-09 起由 `sync_em_concepts`（东财 push2delay 概念板块）补强热点概念（PCB/CPO/液冷/算力等）并合入 concepts；行业标签全覆盖；`sync_tags` + `sync_em_concepts` 采集两者 |
| 流通市值 | `stock_basic.circ_mv / 1e8`（亿） | 直接可用 |
| 量比 | 当日 `vol / vol_ma20` | 直接可用 |
| 5日/20日涨幅 | 库内收盘价现算 | 库内保留约 30 个交易日，够用 |
| RSI(14) | 收盘价 Wilder 算法现算 | 直接可用 |
| 主力净流入 > 2000万 | **已入库+auto 模式**：`stock_money_flow`.main_net（2026-09-08 起前滚积累）。命中原因实时展示真实值；`use_money_flow="auto"`（默认）在积累满 `min_flow_days`(21) 个交易日后**自动启用**硬过滤，True/False 可强制；过滤启用前评分仍用 3日量比代理 |
| 跷跷板确认（主力净流出>50亿） | **代理：主线板块当日平均涨幅 > 5% 判过热** | 板块级资金流汇总待积累后评估 |
| 大盘 5日线死叉 | ✅ **已切换真实数据**：`stock_index_daily` 上证指数 MA5<MA20 判弱势（`use_index_env` 默认开），指数数据缺失时自动回退市场宽度代理 |
| 上市 > 60 日（非新股） | ✅ **已切换真实数据**：`stock_basic`.list_date 距今 ≥ `min_list_days`(60) 天；list_date 缺失个股自动回退库内≥21交易日代理 |
| 非停牌 | 最近交易日必须有行情 | 直接可用 |

## 四、使用方式

```bash
# 前置：确保已采集基础信息 + 板块标签 + 日线行情
python run_collect.py --task tags      # 板块概念标签(策略依赖, 至少跑一次)
python run_collect.py --task quotes    # 日线行情

# 执行选股（每日盘后，已由调度器 15:30 自动触发）
python run_pick.py --strategy WEEKLY_MAINLINE

# 调参示例：放宽 RSI、调整主线概念
python run_pick.py --strategy WEEKLY_MAINLINE --params "{\"rsi14_max\": 75, \"main_concepts\": [\"CPO\",\"PCB\"]}"

# 回测（T-N 日视角模拟选股并统计收益）
# API: POST /backtest/WEEKLY_MAINLINE?days_ago=5
```

## 五、风控纪律（代码外执行）

选股结果仅为候选池，实盘操作需遵守原文档纪律：总仓位 2-3 成、单票约 1%-1.5%、
买入价 -3% 硬止损、盈利 > 5% 上移保本、> 8% 分批止盈、持仓满 3 日未达目标强制平仓。

## 附：环境闸门数据修复与 0 命中判读（2026-09-16）

**恒 0 命中的排查结论：不是死规则，而是大盘环境闸门在正常工作。**

- 2026-09-16 单跑 `WEEKLY_MAINLINE` 恒 `hit_count=0`（批次 `trade_date=NULL`）。逐门复现后确认**唯一原因**是 `_index_env_ok()` 返回 False：上证
  `ma5=3892.75 < ma20=3923.50`，命中策略第 257 行的「弱势不开新仓」早退分支。09-11/09-14/09-15/09-16 连续 4 日死叉，故连日 0 命中。
- **反证（策略本身正常）**：在闸门放行的 09-08 / 09-09 实跑，各出 3 只（如 09-09 东方通信 / 四会富仕 / 本川智能），库内批次 `P20260908-…/P20260909-…` 均 `hit_count=3`。
  闸门通过率：2022-06-23~2026-09-16 全区间 **52.8%（544/1030）**；2026-03 以来 46.4%。

**排查过程中发现并修复的真实缺陷 —— 指数均线大面积 NULL：**

| 项 | 修复前 | 修复后 |
|---|---|---|
| `stock_index_daily` MA 计算 | 只在受限抓取窗口内 `rolling()`，窗口头部 NaN 被写库，**NULL 覆盖正确值** | 多拉 25 根预热 + 丢弃 `ma20` 为 NaN 的行后再写 |
| `sh000001.ma20` NULL | 55/66 行（其中 **2026-07-21~09-08 连续 33 个交易日整段 NULL**） | 0/1030 行 |
| 指数历史覆盖 | 66 个交易日（2026-06-16 起） | **1030 个交易日（2022-06-23 起，~4.2 年）** × 7 指数 |

成因链路：`run_collect --index` 传 `days=25` → `_fetch_index(count=25)` → `rolling(20)` 在 25 行窗口内只有**最后 6 行**有效，其余 19 行 NaN 被 UPSERT 写入 → `ma20` 从 07-21 起整段为空 → 闸门在这些日子静默退化（回退市场宽度代理或误用陈旧值）。

**可发现性改进**：`stock_pick_batch.message` 现有策略给出的执行结论（策略新增 `last_note` 属性，`pick_service.run_pick` 落库）。
WEEKLY_MAINLINE 在闸门拦截时写入 `大盘弱势不开新仓: 上证MA5<MA20(3893/3923)(上证死叉)`，闸门放行时写入 `环境正常(上证MA5≥MA20(...), 宽度..%), 主线候选N只, 出票M只`。
选股结果页顶部以「批次说明：…」展示，避免把**防御性 0 命中**误判为策略故障。

> 运维提示：因指数历史已回填至 2022-06-23，历史回测中环境闸门不再退化到「市场宽度代理」，而是真实上证 MA5/MA20 判定 —— 早前「旧宽度代理放行」的实测行（如 2026-08-27）在重跑回测时会得到真实指数口径的结论，属预期变化。
