# 07 · 回测窗口可测性诊断（WEEKLY_MAINLINE 10/15 日空窗根因）

> 结论先行：**两个空窗均为正确行为，无代码 bug** —— 10 日窗被指数环境门死叉拦截（feature），
> 15 日窗因日线库深度不足触发指标充足性保护（数据限制，保守空池正确）。

## 3. 根因 1：指数环境门死叉拦截（10 日窗）

`weekly_mainline.select()` 环境门：`use_index_env=True` 时取 t0 当日上证 MA5/MA20，
`MA5<MA20 → return []`（弱势不开新仓）。2026-08 月下旬实际指数均线：

|---|---|---|---|
| 2026-08-24 | 3915.13 | 3894.47 | 放行 |
| **2026-08-25** | **3894.96** | **3898.27** | **死叉拦截** |
| 2026-08-26 | 3898.58 | 3902.47 | 死叉拦截 |
| 2026-08-27 | 3909.15 | 3910.07 | 死叉拦截（docs/04 已验证案例） |
| 2026-08-28 | 3918.55 | 3916.07 | 放行 |

08-25~08-27 连续三日死叉，与 docs/04 记载的 08-27 拦截案例同属一类，闸门工作正常。

## 4. 根因 2：日线库深度（15 日窗）

`stock_daily_quote` 逐日覆盖实测（161,441 行总量）：

- **2026-07-28 起全市场统一覆盖**（~5,200 只/日），至 2026-09-08 共 **31 个交易日**，每日 +1 前滚
- 2026-07-09~07-27 仅 1~38 只/日的零星遗留行（早期碎片，无全市场意义）
- 增量采集模式（keep=最近 2 日）只前滚不回溯，深度边界固定从 07-28 起

t0=2026-08-18 时窗内仅 **16 根 K 线 < min_hist_days=21**（RSI14 需 15 根预热、vol_ma20 需 20 根，
21 是保证指标可算的最低门槛）→ 指标充足性阶段全员拦截 → 空池。
**这是正确的保守行为**：指标不可算时不出票，优于用残缺指标硬算。

## 6. 可回测性边界（以 2026-09-08 为基准）

- 最深可回测 t0 = **2026-08-25**（21 根，恰达门槛）⇔ `days_ago ≤ 10`
- 边界每日前移 1 个交易日（深度 31 → 32 → …）
- t0 ∈ [08-25, 08-27] 的窗口虽可算，但均被死叉门拦截（空池为正确输出）
- **>10 日的更深窗口**：需先执行区间模式日线回补（`run_collect.py --quotes` 支持
  start/end 区间，如 2026-06-01~07-27 约 40 交易日 × 5,215 只）+ 对应日期 Baostock
  估值增量回填，预估耗时约 1.5 小时。**默认不执行，待明确需求后再做。**
